## About

This repository documents a hands-on AWS DevOps Mentorship Program. It records the progression from containerized application deployment to production-oriented infrastructure, database integration, service redundancy, and cross-region object replication.

The documentation is evidence-driven: each task includes only the screenshots, commands, configuration details, and validation results captured during that task.
